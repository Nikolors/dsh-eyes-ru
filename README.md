# dsh-eyes-ru — глаза для DeepSeek Harness

Набор инструментов, который даёт ассистенту «зрение» на Windows: снимок экрана,
активного окна или монитора, камера, чтение текста с экрана, описание кадра
локальной моделью и разметка того, как человек говорит.

Сделано для русской речи и локального запуска: ничего не уходит в облако, кроме
случая, когда явно включены облачные глаза.

## Что внутри

- `tools/grab_screen.py` — снимок экрана: весь экран, активное окно, конкретный
  монитор, окно по фрагменту заголовка (`title:YouTube`).
- `tools/ocr_screen.py` — распознавание текста на снимке встроенным движком
  Windows (`Windows.Media.Ocr`), русский язык. Дешевле и точнее, чем читать
  картинку целиком, когда нужен код, консоль или мелкий текст.
- `tools/eyes.py` — всё в одной утилите: `shot`, `camera`, `text`, `look`, `ask`.
- `tools/cloud_eyes.py` — облачные глаза на Qwen-Omni (Alibaba DashScope):
  кадр → короткое описание. Нужен ключ и оплата, включать по желанию.
- `tools/watch_video.py` — смотрит экран и складывает распознанные субтитры в ленту.
- `tools/tone_of_speech.py` — физика речи через openSMILE: громкость, пик,
  высота голоса (F0), длительность.
- `tools/emotion_of_speech.py` — эмоция в речи русской моделью на HuBERT,
  обученной на датасете DUSHA (нейтрально, гневно, грустно, радостно).
- `tools/smart_turn.py` — определение «договорил ли человек» по звуку
  (Smart Turn v3.2, ONNX; файл модели скачивается отдельно).

## Что установить

```bat
pip install pillow winsdk soundfile opensmile opencv-python
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install transformers onnxruntime
```

Модель эмоций скачается при первом запуске (`xbgoose/hubert-large-...-dusha`,
около 1,2 ГБ). Модель Smart Turn нужно положить в `tools/smart-turn/` вручную:
`smart-turn-v3.2-cpu.onnx` с Hugging Face (`pipecat-ai/smart-turn-v3`).

## Как пользоваться

```bat
python tools\eyes.py shot                 :: снимок всего экрана, печатает путь
python tools\eyes.py shot window          :: активное окно
python tools\eyes.py shot monitor 1
python tools\eyes.py camera               :: кадр с камеры
python tools\eyes.py text window          :: текст из активного окна
python tools\eyes.py look camera          :: кадр + описание локальной моделью
python tools\eyes.py ask frame.jpg "Что на экране?"
```

Каталог для снимков задаётся `EYES_OUT` (по умолчанию `frames`).

## Разметка речи

`tone_of_speech.py` и `emotion_of_speech.py` рассчитаны на то, чтобы вызывать их из
своего слухового цикла и приписывать к распознанной фразе ярлык:

```
[тише обычного, спокойно, нейтрально] Какой сегодня день…
```

Громкость сравнивается со скользящей средней самого пользователя, а не с
фиксированным порогом — иначе на разных микрофонах получается ерунда.

## Ограничения

- Камера работает только при открытой крышке ноутбука; с закрытой кадры чёрные.
- Распознавание эмоций по звуку — приблизительное: громко не всегда значит гневно.
- Облачные глаза платные и требуют ключ Alibaba Cloud; локальная модель описаний
  слабее, но бесплатна.
- Имена файлов лучше держать латиницей: часть инструментов не находит пути с
  кириллицей.

## Плагин

`plugin/` — bundle для DSH: ставится через **Plugins → Add plugin** (указать папку)
и добавляет агенту инструменты `eyes_capture`, `eyes_text` и `eyes_camera_shot`.

Пути к Python и к папке скриптов задаются в строке плагина в `cordis.patch.yml`.
