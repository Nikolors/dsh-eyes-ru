# Глаза

Плагин даёт агенту три инструмента:

- **eyes_capture** — снимок всего экрана, активного окна или выбранного монитора,
  возвращает путь к сохранённому изображению.
- **eyes_text** — чтение текста с экрана встроенным распознаванием Windows,
  построчно. Дешевле и точнее, чем разбирать картинку, когда нужен код,
  консоль или мелкий шрифт.
- **eyes_camera_shot** — один кадр с веб-камеры.

Снимки складываются в каталог из `EYES_OUT` (по умолчанию `frames` рядом со
скриптами). Пути к Python и к папке скриптов задаются в настройках плагина.

Ограничения: камера работает только при открытой крышке ноутбука; OCR читает
только то, что видно на экране, и не понимает рукописный текст.
